Handoff: Dashboard ข้าวนาปรัง

เป้าหมาย ข้อมูลหลักที่สำรวจแล้ว แหล่งข้อมูล โครงสร้างข้อมูล หน้า dashboard งานที่ต้องทำ เรื่องที่ต้องตัดสินใจ กติกาสำหรับ AI ที่รับช่วง prompt ส่งต่อ

เป้าหมายและบริบท

แก้ข้อความในกรอบได้โดยตรง

สร้าง dashboard เชิงโต้ตอบเรื่องข้าวนาปรัง ปี 2565–2568 ใน Antigravity สำหรับงานส่งอาจารย์ในรายวิชา โดยใช้เฉพาะข้อมูลที่เป็น Open Data ของไทยเป็นหลัก ครอบคลุมจังหวัดให้มากที่สุด

บริบทที่ผู้ใช้แจ้งไว้

  • อาจารย์ให้หาข้อมูลเปิดเอง แล้วทำ dashboard ด้วย Antigravity
  • ผู้ใช้ต้องการข้อมูลที่ครอบคลุมทั้ง 77 จังหวัด แต่ชุดข้อมูลข้าวนาปรังมีเพียงประมาณ 70–73 จังหวัดต่อปี (ดูเรื่องที่ต้องตัดสินใจ)
  • ภาษาที่ใช้สื่อสารกับผู้ใช้: ไทย

ข้อสังเกตที่ควรเป็นจุดเด่นใน dashboard

  • เนื้อที่ปลูกปี 2568 สูงกว่าปี 2565 ประมาณ 32.5% ผลผลิตสูงขึ้นประมาณ 33.7% ส่วนผลผลิตต่อไร่แทบไม่เปลี่ยน (646–653 กก.) แปลว่าผลผลิตรวมเปลี่ยนตามเนื้อที่ไม่ใช่ตามผลผลิตต่อไร่
  • ปี 2567 เนื้อที่ปลูกลดจากปี 2566 ประมาณ 5% แล้วปี 2568 เพิ่มประมาณ 26%
  • ภาคเหนือเติบโตเร็วสุด เนื้อที่ปลูกเพิ่มประมาณ 61% จากปี 2565 ถึง 2568 ภาคอีสานประมาณ 28% ภาคกลางประมาณ 13%
  • ปี 2568 จังหวัดเนื้อที่ปลูกมากสุด: นครสวรรค์ ~911,000, สุพรรณบุรี ~906,000, พิษณุโลก ~831,000, พิจิตร ~825,000, พระนครศรีอยุธยา ~714,000 ไร่
  • จุดเปลี่ยนผิดปกติ: สุรินทร์ 43,695 → 124,811 ไร่ (2567→2568), นครราชสีมา 270,262 → 93,750 → 139,061 ไร่ (2566→2567→2568), เพชรบุรี 147,844 → 81,675 → 174,335 ไร่ (2566→2567→2568)
  • ผลผลิตต่อไร่สูงสุดอยู่ภาคกลาง (นครปฐม 775, อยุธยา 755, สุพรรณบุรี 748 กก./ไร่ ปี 2568) ส่วนเลยต่ำสุดในชุดหลักที่ประมาณ 400

ปัญหาที่ต้องจัดการ

  • ข้อความจาก PDF ทำให้วรรณยุกต์และสระบางตัวหาย (เช่น "เชียงใหม" "ขาวนาปรัง") และสะกดชื่อไม่ตรงกันข้ามปี (เช่น "กาฬสนิธุ", "ประจวบครีีขันธ") ให้ map ชื่อกับตารางรหัสจังหวัดของ COD-AB แล้วตรวจจังหวัดที่ไม่ match ด้วยมือ
  • ตำแหน่งและหัวตารางต่างกันในแต่ละปี และมีหัวตารางซ้ำกลางหน้า ต้องตัดแถวหัวออกก่อนรวม
  • จังหวัดที่ไม่ปลูกนาปรังไม่มีแถว ให้เก็บเป็น "ไม่มีข้อมูล" แยกจาก 0 และอธิบายในหน้า "ที่มาข้อมูล" (ตัวอย่าง: สตูลมีเฉพาะปี 2565 และ 2568, ยะลามีเฉพาะปี 2568, จันทบุรีไม่ปรากฏ)
  • ตรวจความสอดคล้อง: ผลรวมจังหวัดต้องใกล้เคียงยอดภาค และผลรวมภาคใกล้เคียงยอดประเทศ (ยอมรับความต่างจากการปัดเศษ) ยังไม่ได้ตรวจในรอบนี้
  • เนื้อที่เก็บเกี่ยวของบางจังหวัดมากกว่าเนื้อที่ปลูก และผลผลิตบางจังหวัดมีทศนิยม (สตูล 4.48 ตัน) ให้เก็บค่าตามต้นทาง ไม่ปรับแก้

หน้าและกราฟของ dashboard

ข้อเสนอเริ่มต้น แก้หรือลบได้

  • ภาพรวม: การ์ดตัวเลขระดับประเทศ (เนื้อที่ปลูก ผลผลิต ผลผลิตต่อไร่) และกราฟเส้นปี 2565–2568 เลือกตัวชี้วัดได้
  • แผนที่: choropleth รายจังหวัด สลับปีและตัวชี้วัด จังหวัดไม่มีข้อมูลแสดงเป็นสีเทาพร้อมคำอธิบาย
  • ภาค: แท่งซ้อนเปรียบเทียบ 4 ภาคตามปี และสัดส่วนเนื้อที่
  • จังหวัด: ตารางจัดอันดับ Top 10 พร้อม YoY ค้นหาและเรียงได้ และไฮไลต์จังหวัดที่เปลี่ยนผิดปกติ
  • ระดับ: scatter เนื้อที่ปลูกเทียบผลผลิตต่อไร่ แยกสีตามระดับ (ต่ำ/กลาง/สูง)
  • ปัจจัย (ทำถ้ามีเวลา): ฝน/อุณหภูมิจาก NASA POWER เทียบผลผลิตต่อไร่ และฤดูกาลเก็บเกี่ยวจาก D2
  • ที่มาข้อมูลและข้อจำกัด: ตารางแหล่งข้อมูล สิทธิ์ใช้งาน เครดิตตามที่แต่ละแหล่งกำหนด และคำอธิบายว่าทำไมไม่ครบ 77 จังหวัด

งานที่ต้องทำ

ติ๊กเมื่อเสร็จ แล้วกด "บันทึกเป็นไฟล์ HTML" เพื่อเก็บสถานะ

  • สำรวจข้อมูล D1 และสรุปภาพรวม
  • ค้นหาแหล่ง Open Data และเขียนแคตตาล็อก (rice_open_data_catalog.md)
  • แปลง PDF 4 ไฟล์เป็น rice_offseason_long.csv (ลองหลายตัวสกัด เช่น pdfplumber หรือ pdftotext แล้วเทียบกับ PDF จริง)
  • แก้ชื่อจังหวัดและผูก adm1_pcode จาก COD-AB ทำรายงานจังหวัดที่ไม่ match
  • ตรวจผลรวมจังหวัดเทียบยอดภาคและประเทศ บันทึกผลตรวจ
  • คำนวณ YoY และระดับ (tier) ตามกติกาเปอร์เซ็นไทล์ 33/67 ต่อปี
  • ดาวน์โหลด COD-AB ตัดเฉพาะระดับจังหวัด และ simplify เป็น GeoJSON ขนาดเล็ก
  • ตรวจ D2 และ D3 ว่ามีข้อมูลย้อนหลังและ schema อะไรบ้าง ตัดสินใจว่าจะใช้หรือไม่
  • สร้างหน้า dashboard ตามหัวข้อ "หน้าและกราฟ" ใน Antigravity
  • ตรวจเกณฑ์ความสำเร็จด้านล่าง แล้วเขียนหน้า "ที่มาข้อมูลและข้อจำกัด"

เกณฑ์ความสำเร็จ

  • ทุกตัวเลขใน dashboard ตรงกับ CSV ที่แปลง และ CSV ตรงกับ PDF ต้นทางในจังหวัดตัวอย่างอย่างน้อย 10 จังหวัดต่อปี
  • แสดงที่มา สิทธิ์ใช้งาน และเครดิตของทุกแหล่งในหน้า dashboard
  • ระบุชัดเจนว่าค่าใดคำนวณเอง (YoY, tier) และค่าใดมาจากต้นทาง
  • ใช้งานได้บนจอมือถือและเดสก์ท็อป ภาษาไทยแสดงถูกต้อง

เรื่องที่ต้องตัดสินใจ

เรื่องตัวเลือก / คำแนะนำสถานะ
ข้อมูลไม่ครบ 77 จังหวัดถามอาจารย์ว่ารับได้หรือไม่ หรือแสดงจังหวัดที่ไม่มีข้อมูลเป็นสีเทา (ไม่เติมเป็น 0 โดยไม่บอก)
ฐานผลผลิตต่อไร่ที่ใช้เป็นค่าเริ่มต้นฐานเนื้อที่ปลูก หรือฐานเนื้อที่เก็บเกี่ยว (ต่างกันเล็กน้อย) ควรมีตัวสลับและบอกชัดเจน
แหล่งสภาพอากาศNASA POWER (D4) หรือ Open-Meteo (D5) เลือกแหล่งเดียว
ปีย้อนหลังเพิ่มถ้าชุด สศก. บน data.go.th (nabc-oae00232) มีข้อมูลตั้งแต่ปี 2557 จริง ให้ขยายแนวโน้มเกิน 4 ปี
หมวดราคา/ต้นทุน/ตลาดส่งออกข้อมูลครอบคลุมน้อย แนะนำให้เป็นหน้าเสริมหรือตัดออกจากเวอร์ชันแรก

กติกาสำหรับ AI ที่รับช่วง

  • อย่าสร้างตัวเลขหรือแถวข้อมูลที่ไม่มีในต้นทาง ถ้าอ่านค่าไม่ได้ให้ทำเครื่องหมายและถามผู้ใช้
  • แยกให้ชัดว่าค่าใดอ่านจากต้นทาง และค่าใดคำนวณเอง
  • อย่าอ้างว่า dataset มีสิทธิ์เปิดโดยไม่ได้อ่านหน้า dataset เอง และอย่าเดาลิงก์ดาวน์โหลดตรง
  • ใส่เครดิตตามที่แต่ละแหล่งกำหนด (NASA POWER, HDX CC BY-IGO, กรมชลประทาน CC BY, Open-Meteo CC BY 4.0 ถ้าใช้)
