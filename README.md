# Dashboard ข้าวนาปรัง

## เป้าหมาย
สร้าง dashboard เชิงโต้ตอบเรื่องข้าวนาปรัง ปี 2565–2568 สำหรับงานส่งอาจารย์ในรายวิชา โดยใช้เฉพาะข้อมูลที่เป็น Open Data ของไทยเป็นหลัก ครอบคลุมจังหวัดให้มากที่สุด

## ข้อมูลที่ใช้
- **D1**: เนื้อที่เพาะปลูก เนื้อที่เก็บเกี่ยว ผลผลิต ผลผลิตต่อไร่ ข้าวนาปรัง ปี 2565–2568 (ไฟล์ PDF จาก สศก.)
- **D2**: ร้อยละและปริมาณผลผลิตข้าวนาปรังรายเดือน ระดับจังหวัด
- **D3**: สภาพน้ำในอ่างเก็บน้ำขนาดใหญ่
- **D4/D5**: ข้อมูลสภาพอากาศ (NASA POWER / Open-Meteo)
- ขอบเขตการปกครองระดับจังหวัด (COD-AB)

## คำถามที่ Dashboard ต้องตอบ
1. ปีและจังหวัดใดปลูกนาปรังมากที่สุด และเปลี่ยนไปอย่างไรช่วง 2565–2568
2. ผลผลิตต่อไร่ของภาคและจังหวัดต่างกันเท่าไร จังหวัดไหนสูง/ต่ำกว่าค่าเฉลี่ยประเทศ
3. จังหวัดใดเนื้อที่ปลูกเพิ่มหรือลดผิดปกติเมื่อเทียบกับปีก่อน
4. เก็บเกี่ยวกระจุกตัวในเดือนใดของแต่ละจังหวัด
5. น้ำในเขื่อนและสภาพอากาศช่วงปลูกสัมพันธ์กับเนื้อที่ปลูกและผลผลิตต่อไร่หรือไม่
