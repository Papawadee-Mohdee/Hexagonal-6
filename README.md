# Dashboard ข้าวนาปรัง รายจังหวัดและภูมิภาค (ปี 2565–2568)

Dashboard เชิงโต้ตอบสำหรับแสดงข้อมูลเนื้อที่เพาะปลูก เนื้อที่เก็บเกี่ยว และผลผลิตข้าวนาปรัง ครอบคลุม 77 จังหวัดทั่วประเทศไทยในช่วงปี พ.ศ. 2565 ถึง 2568

## ✨ ฟีเจอร์หลัก

- **แผนที่ภูมิศาสตร์ (Choropleth Map):** แสดงระดับผลผลิต/เนื้อที่ปลูกด้วยความเข้มของสี พร้อมระบบ Zoom อัตโนมัติเมื่อเลือกพื้นที่
- **Cross-filtering แบบสองทาง:** เมื่อคลิกที่แผนที่, กราฟโดนัท หรือเลือกจากเมนูด้านซ้าย ทุกส่วนของ Dashboard จะกรองข้อมูลและอัปเดตไปพร้อมกัน
- **ระบบเจาะลึกข้อมูล (Drill-down):** สามารถคลิกเลือกภูมิภาคเพื่อดูสัดส่วนและเปรียบเทียบข้อมูลย่อยระดับจังหวัดภายในภาคนั้นได้
- **ตัวกรองและ KPI:** กรองข้อมูลตามปี พ.ศ. และแสดงตัวเลขรวม (เนื้อที่เพาะปลูก, เก็บเกี่ยว, ผลผลิต, ผลผลิตต่อไร่) อัตโนมัติตามพื้นที่ที่เลือก
- **Dark Mode:** รองรับการแสดงผลทั้งธีมสว่างและธีมมืด

## 🚀 วิธีรันบนเครื่อง (Local Development)

ระบบ Dashboard ถูกเขียนด้วย HTML, CSS และ JavaScript ธรรมดา (Vanilla JS) ไม่ต้องทำการ Build สามารถรันผ่าน Local Web Server ได้ทันที

1. **โคลนโปรเจกต์และรันเซิร์ฟเวอร์:**
   ```bash
   git clone https://github.com/Papawadee-Mohdee/Hexagonal-6.git
   cd Hexagonal-6
   python -m http.server 8080
   ```
2. **เปิดเบราว์เซอร์** ไปที่ `http://localhost:8080`

**กรณีต้องการรัน Data Pipeline (Python):**
ต้องใช้ Python 3.8+ และติดตั้งไลบรารีดังนี้:
```bash
pip install pandas geopandas requests fuzzywuzzy python-Levenshtein PyMuPDF
```

## ⚙️ Data Pipeline

ลำดับการแปลงข้อมูลจากไฟล์ PDF ต้นฉบับจนถึงไฟล์ CSV ที่ใช้ใน Dashboard:

1. **`extract_fitz.py`**: อ่านข้อความดิบจากไฟล์ `2565.pdf` ถึง `2568.pdf` ส่งออกเป็นไฟล์ `output_fitz.txt`
2. **`parse_txt_to_csv.py`**: สกัดข้อความและจับกลุ่มตัวเลข 5 คอลัมน์จากไฟล์ TXT แปลงเป็นตารางเบื้องต้นใน `temp_parsed.csv`
3. **`generate_mapping.py`**: สคริปต์หลักในการทำความสะอาดข้อมูล! ทำหน้าที่:
   - ตรวจจับและแก้ไขชื่อจังหวัดที่สะกดผิดเพี้ยนจากการสกัด PDF (Fuzzy Matching)
   - แมปรหัสจังหวัด (PCODE) และจัดกลุ่ม 6 ภูมิภาค
   - ส่งออกผลลัพธ์เป็น `rice_offseason_cleaned_v2.csv` (ไฟล์ที่ Dashboard ใช้)
   - สร้างไฟล์ตรวจสอบ: `mapping.csv` (คู่มือแมปชื่อ), `raw_names.csv`, `unmapped.csv`, และ `missing.csv` (รายชื่อจังหวัดที่ไม่มีในข้อมูล)
4. **`simplify_geo.py`**: ดาวน์โหลด Shapefile จาก HDX ทำการยุบจุดยอด (Simplify) ให้ไฟล์เล็กลง และแปลงเป็น `thailand_provinces.geojson`

*(สคริปต์ `clean_data.py` เป็นเวอร์ชันเก่าที่ถูกแทนที่ด้วย `generate_mapping.py` แล้ว)*

## 🗺️ การแบ่งภูมิภาค

โปรเจกต์นี้ใช้เกณฑ์การแบ่งภูมิภาคเป็น **6 ภาค ตามหลักเกณฑ์ของคณะกรรมการภูมิศาสตร์แห่งชาติ** ได้แก่:
1. **ภาคเหนือ:** 9 จังหวัด
2. **ภาคตะวันออกเฉียงเหนือ:** 20 จังหวัด
3. **ภาคกลาง:** 22 จังหวัด
4. **ภาคตะวันออก:** 7 จังหวัด
5. **ภาคตะวันตก:** 5 จังหวัด
6. **ภาคใต้:** 14 จังหวัด

## ⚠️ ข้อจำกัดและงานที่ยังไม่เสร็จ

- **จังหวัดที่ไม่มีข้อมูล:** ข้อมูลต้นฉบับจาก สศก. ไม่มีรายงานการทำนาปรังใน 4 จังหวัด ได้แก่ **จันทบุรี, ภูเก็ต, พังงา, และ ระนอง** (ข้อมูลจึงแสดงเป็นสีเทาบนแผนที่)
- **ไฟล์ Shapefile ต้นฉบับ:** ไฟล์ `tha_admin_boundaries.shp.zip` (ขนาดเกือบ 400MB) ไม่ได้ถูกอัปโหลดขึ้น Repository นี้ หากต้องการสร้าง GeoJSON ใหม่ ต้องให้สคริปต์ `simplify_geo.py` ดาวน์โหลดใหม่
- **Bug ที่ทราบ:** เมื่อย่อหน้าต่างเป็นขนาดมือถือ (Mobile) กราฟแท่ง (Bar Chart) อาจจะยังแสดงผลได้ไม่เต็มที่ตามความกว้าง
